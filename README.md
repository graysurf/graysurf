## About Me

Backend and platform engineer with 10+ years of experience across distributed services, data platforms and
cloud-native delivery. I help teams turn unsettled requirements and tangled system boundaries into clear
structures they can build on.

I run **[Sympoies](https://sympoies.com)**, a professional software development team. We take on contract
development, advise engineering teams, and help them bring AI into the way they already work, with quality and
accountability staying with their people.

## What I do

- **Software development** — web services, APIs, internal tools and platforms, from first design to release,
  with automated tests and code review as standard practice.
- **Technical consulting** — architecture and codebase reviews, delivery process assessments, technology
  selection, and hands-on guidance so teams can make and carry out sound technical decisions.
- **AI workflow adoption** — where AI assistance fits in a team's process and where it does not; review,
  testing and approval practices for AI-assisted changes; shared conventions and tooling; training and handover
  so the team owns the workflow.

## Experience

- **Backend and platform architecture** — service boundaries, API and data-model design, and shared backend
  baselines that keep many projects consistent.
- **Data platforms** — Spark, ELK, PostgreSQL, Elasticsearch and Neo4j pipelines and query systems at
  billions-of-records scale.
- **Cloud-native delivery and CI** — Docker, Kubernetes, AWS and GCP; GitHub Actions and GitLab CI;
  test-first gates and repeatable, documented releases.
- **Languages** — Rust, TypeScript / Node.js, Go, Java / Spring Boot, Python, Scala and shell.

## How I work

- Agree what success looks like before any code is written.
- Settle the approach and the main trade-offs, and write them down.
- Specify behavior with tests first, then build in small, reviewable steps.
- Review every change before it is merged, and make releases routine.
- Hand over code, documentation and knowledge, so the team can run and extend the result without me.

## Open source

Selected public work under [Sympoies](https://github.com/sympoies):

- [**nils-cli**](https://github.com/sympoies/nils-cli) — a Rust workspace of focused command-line tools with
  stable JSON output, for Git, GitHub/GitLab automation, API testing and release work.
- [**salon**](https://github.com/sympoies/salon) — a self-hostable chat workspace for working with coding
  assistants from a browser.
- [**symphony-board**](https://github.com/sympoies/symphony-board) — a read-only board for GitHub/GitLab issues,
  pull requests and activity across providers.
- [**agent-collab**](https://github.com/sympoies/agent-collab) — collaboration between people and their AI
  assistants through a Git repository, with a read-only chat-style viewer.
- [**host-monitor**](https://github.com/sympoies/host-monitor) — a read-only dashboard for Linux host resources,
  services and containers.
